## 组件说明

| 组件 | 说明 |
|------|------|
| Streamlit 前端 | 本地交互界面，6 个 demo 页面，入参→运行→结果/日志 |
| Chaining Runtime | 代码编排引擎：顺序/并行/Map/条件/人工确认，全链路可回放 |
| ModelAdapter | 唯一直连 MaaS 的模块，封装 OpenAI 兼容 API |
| MaaS | ModelArts Studio 大模型服务，按调用量结算 |

## 部署形态

| 形态 | 说明 |
|------|------|
| 本地运行 | `streamlit run frontend/app.py`，需要 MAAS_API_KEY |
| 函数计算部署 | 每个 demo 的 handler 打包为 FunctionGraph 函数 |
| 离线演示 | `python -m techniques.*`，无需 API Key，使用 ScriptedAdapter |

## 编排原语

1. **顺序链**: `model_turn` 自动累积历史
2. **并行**: `runtime.parallel([lambda: ..., lambda: ...])`
3. **Map**: `runtime.map_items(list, fn, concurrency=3)`
4. **条件**: Python 原生 `if/else`
5. **人工确认**: 抛 `HumanInputRequired` 信号，页面收集答复后续跑
