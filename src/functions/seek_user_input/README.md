# seek_user_input —— 人工确认节点占位 Worker

「先暂停等人拍板、再继续」的语义在无状态函数形态下需要令牌/会话存储
（把「问题 + 任务令牌」交给后端，等用户在 UI 作答后推回令牌续跑）。

本示例的代码编排形态用 **HumanInputRequired 异常信号**表达同一语义
（`src/chaining/runtime.py`）：
- 链执行到确认点 → 抛信号，返回问题清单 + 回放缓存 + 业务中间态；
- 调用方（页面/入口函数）展示问题并收集答复；
- 带着答复 + 回放缓存重新执行 → 已完成的模型节点原样回放，只从答复后的
  步骤继续，不重复调用模型。

本 Worker 保留为「可部署占位参考」：联调时把问题与上下文持久化到自己的
会话后端即可对接任意 UI。
